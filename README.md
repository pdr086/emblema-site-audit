# Аудит сайта студии «Эмблика»

**Дата отчёта — 11.06.2026** · [Сайт студии в Брянске](https://emblema.tw1.ru/)

**Студия хорошо представлена, но демонстрация теряет посетителя на выборе времени.** Из каталога можно перейти к записи на конкретную услугу с уже выбранной ценой. Для женского маникюра за 700 ₽ сайт предложил одного мастера, затем показал отсутствие свободного времени на восьми проверенных датах подряд. На этом шаге посетителю предлагается перебирать даты вручную. Для настоящего визита сами правила сайта предлагают звонить в студию.

[Полный аудит по разделам](AUDIT.md) · [Методика, дата замеров и результаты проверок](METHOD.md)

| Очерёдность | Что изменить | Как понять, что готово |
|---|---|---|
| 1. До следующего показа | Подготовить демонстрационные окна и дать переход к ближайшему свободному дню | Новый посетитель выбирает услугу, видит доступное время либо может сразу выбрать другой способ связи |
| 2. До приёма клиентов | Согласовать реальный порядок записи и обработки обращений, заполнить реквизиты, связать расписание с работой студии | Клиенту и администратору понятно, кем и когда подтверждается визит. Пробная запись проходит весь согласованный цикл |
| 3. До продвижения | Подготовить основной HTTPS-домен, самостоятельные адреса разделов и доступный без JavaScript блок контактов | Прямой переход открывает нужный раздел. Телефон доступен при сбое загрузки приложения. Демо сохраняет собственные настройки индексации |
| 4. На ближайшей итерации | Сократить выбор из 185 позиций в форме и пересмотреть показ прайса на телефоне | Человек находит процедуру по названию или направлению и видит подходящего мастера без повторного поиска |
| 5. На ближайшей итерации | Исправить возврат клавиатурного фокуса и переход к основному содержимому, облегчить фотографии | После закрытия фото фокус остаётся в галерее. Обновление страницы сохраняет раздел. Сравнимый холодный визит передаёт меньше данных |

Проверены семь разделов сайта, три самостоятельные страницы документов и публичный экран входа в кабинет. В полном отчёте приведены результаты по записи, обучению, сертификатам, поиску услуг, карте, отзывам, доступности, скорости и готовности к запуску. Замеры относятся к публичной версии, доступной во время проверки.
